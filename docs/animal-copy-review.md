# Animal copy review

## Editorial decisions

- Keep species names as supplied: `Belted Galloway × Jersey`, `Kune Kune Pigs`, `Nigerian Dwarf Goats`, and `Mini Horse & Donkey` remain recognizable reference labels.
- Keep named-animal spellings exactly as the source provides them, including `Chiri Bim`, `Freidrick`, `Soloman`, and lowercase `mauve`. These are data fidelity markers, not copy-edit errors.
- Translate breed notes into short, plain context sentences on the card. Do not add husbandry, temperament, availability, or safety promises that the source does not make.
- For-sale rows show the supplied detail and an inquiry CTA only. No price, urgency, or inventory guarantee is inferred from an empty source price.

## Source anomalies to flag, not silently fix

The source contains mixed capitalization, a cross-breed multiplication sign, and a lowercase individual name. The build preserves these values and the page exposes them as reference data; a future farm-owner edit can correct them explicitly if desired.
